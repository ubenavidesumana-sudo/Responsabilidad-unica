# Responsabilidad-nica
Este dice que una clase debe tener una sola responsabilidad (solo deberia cambiar por una razón) como el ejemplo de boton visto en clase.. En el ejemplo, la clase Libro guarda los datos del libro, como el título y el autor, mientras que la clase Guardar se encarga de guardar la información. Así, cada clase tiene una tarea diferente y el código es más fácil de mantener.
